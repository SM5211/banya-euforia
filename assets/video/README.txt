Сюда кладётся фоновое видео для hero — файл должен называться hero.mp4.

Как только файл появится здесь, он автоматически подхватится: в index.html
у тега <video> уже прописан data-src="assets/video/hero.mp4".
Видео включается только на экранах шире 780px, без звука, зациклено;
на телефонах и при системной настройке «уменьшить движение» остаётся фото.

Требования к ролику:
  • без вшитого текста и титров — поверх него идёт заголовок сайта;
  • 8-15 секунд, желательно горизонтальный или квадратный кадр;
  • до ~5 МБ, mp4 (H.264). Сжать можно так:
      avconvert --source исходник.mp4 --preset Preset960x540 --output hero.mp4 --replace
